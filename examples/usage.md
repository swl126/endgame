# Usage Examples

## Software build

```text
/ENDGAME
Build a small REST API for inventory management. Use PostgreSQL, include tests, Docker support, and a README. Do not declare completion until the tests and container build pass.
```

## Research

```text
/ENDGAME
Compare three approaches to securing a private Ethereum-compatible validator network. Use primary technical sources where possible, identify tradeoffs, and recommend one architecture.
```

## Document/artifact

```text
/ENDGAME
Create a 12-page executive whitepaper from the attached source material. Preserve the supplied facts, add citations, include two diagrams, and inspect the final PDF for missing or clipped content.
```

## Debugging

```text
/ENDGAME
This deployment succeeds but the service cannot reach the database. Find the root cause, fix it, verify connectivity, and explain only the final diagnosis and changes.
```

## Without slash-command support

```text
Apply the ENDGAME high-rigor workflow to the following task. Define acceptance criteria, execute fully, test the actual output, adversarially review it, and only call it complete if the criteria pass.
```
