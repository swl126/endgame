# Contributing

Open an issue before proposing a behavioral expansion. Keep ENDGAME focused on high-rigor orchestration rather than accumulating unrelated prompt rules.

Before committing, run:

```bash
python scripts/validate_skill.py
```

Changes to runtime behavior must update `SKILL.md`, the relevant examples or templates, `CHANGELOG.md`, and `VERSION` when the change is releasable.

Contributions are accepted under GPL-3.0-or-later.
